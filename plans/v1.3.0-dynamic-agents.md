# Plan: Dynamic Agents & Workflows (v1.3.0)

## Goal
Replace the 3 hardcoded crews with a fully dynamic system where users can:
1. Create custom agents (role, goal, backstory, tools, LLM override)
2. Create workflows as DAGs — tasks with dependency edges, parallel execution, agent-to-agent delegation
3. Run any agent or workflow on demand from the UI

## New API Endpoints

```
GET    /api/agents              — list all agents
POST   /api/agents              — create agent
GET    /api/agents/{id}         — get agent
PUT    /api/agents/{id}         — update agent
DELETE /api/agents/{id}         — delete agent

GET    /api/workflows           — list all workflows
POST   /api/workflows           — create workflow
GET    /api/workflows/{id}      — get workflow
PUT    /api/workflows/{id}      — update workflow
DELETE /api/workflows/{id}      — delete workflow

GET    /api/tools               — list available tools with descriptions

POST   /api/run/workflow/{id}   — run a workflow with a prompt
POST   /api/run/agent/{id}      — run a single agent with a prompt (single-task crew)
```

## DAG Execution Engine (`crew_executor.py`)

```
1. Load workflow definition
2. Build dependency graph
3. Topological sort → identify execution levels
4. For each level:
   a. Tasks with no unmet dependencies run in parallel (asyncio.gather)
   b. Each task's output is stored and passed as context to dependent tasks
5. Return final output (last task's result or merged results)
```

For CrewAI integration:
- Each "level" of independent tasks becomes a separate `Crew` with `Process.sequential`
- OR: use `Process.hierarchical` with a manager LLM for full delegation
- Parallel branches: run as concurrent asyncio tasks, each wrapping a single-agent Crew

## Frontend Architecture

### New tabs in `App.tsx`
1. **Run** — pick workflow or agent, enter prompt, see live output (existing, updated)
2. **Agents** — CRUD editor for agents
3. **Workflows** — React Flow DAG canvas
4. **Settings** — existing

### React Flow DAG Canvas
- Nodes = tasks (show task name + assigned agent)
- Edges = dependencies (drag to connect)
- Sidebar panel: edit selected task (name, description, agent, expected output)
- Toolbar: add task, delete task, set process type (sequential/hierarchical/dag)

### Dependencies
- `@xyflow/react` (React Flow v12) — DAG canvas
- No other new dependencies

## Default Workflows (seeded on first run)

1. **Code Review** — Developer → Reviewer → DevOps (sequential)
2. **HA Automation** — Read State → Generate YAML → Commit (sequential)  
3. **HA Assistant** — Survey Sensors → Suggest Automations → Apply (sequential)

These are created as editable workflow definitions in `/data/workflows.json`.
